# Дополировка MVP

Основа: `dev` (`7d56bab`). PR #27 с настройками объединён с сохранением его
истории; конфликт обработчиков сообщений разрешён. PR #28 с общими и личными
закрепами уже входит в основу. Изменения бэкенда и миграции не требуются.

## Что изменилось

- Профиль стал экраном аккаунта: имя, аватар, копируемый тег, редактирование,
  приватность, сообщения, оформление, текущий сервер и подтверждение выхода.
  Подписи отражают действующие настройки. Редактирование вынесено в отдельное
  состояние, отмена восстанавливает исходные поля.
- Имя и аватар в шапке личного чата, имена авторов сообщений и строки участников
  открывают профиль человека: фото, имя, тег, описание, дата регистрации и
  последняя активность из API. Из профиля можно открыть личный чат. Онлайн-статус
  не выдумывается: сервер сейчас предоставляет timestamp последней активности.
- Информация о группе разделена на шапку, закрепы, участников и действия с чатом.
  Поиск для добавления раскрывается отдельно и доступен только владельцу/админу.
  Скрытие и выход подтверждаются; заголовок и закрытие остаются видимыми при прокрутке.
  При открытии окно возвращается к началу; фокус не попадает в свёрнутый поиск участников.
- Настройки вынесены в XAML. Enter/Ctrl+Enter, двойной клик, реакция по умолчанию,
  поиск по тегу и оформление доступны с клавиатуры. Локальные настройки теперь
  читаются при старте, проверяются и показывают ошибку записи вместо молчаливой потери.
  Сохранение профиля не перезаписывает приватность.
- Плейсхолдер и текст сообщения имеют одинаковый отступ; центр пустой строки
  совпадает с центром кнопки отправки. Проверены одна и несколько строк.
  Enter не отправляет незавершённую IME-композицию или пустой черновик.
- Реакции используют встроенные изображения Twemoji 17.0.3, без загрузки из сети.
  Единая палитра используется в сообщениях и настройках, подписи доступны
  автоматизации. Чипы стали кнопками, доступными через Tab/Enter.
  Лицензия CC BY 4.0 и атрибуция включены в сборку.
- Меню сообщений появляется по наведению или клавиатурному фокусу. После
  объединения PR обработчик двойного клика не поглощает нажатия кнопок меню.
- Закрепы вынесены в отдельный компонент: ровные строки, область видимости,
  дата, переход к сообщению и снятие закрепа. Личный и общий закреп одного
  сообщения остаются независимыми. Пустое состояние объясняет следующий шаг.
- Исправлены отступы кнопки показа пароля; окно подтверждения учитывает ширину
  родительского окна. Новые служебные иконки — Lucide, как в остальном клиенте.
- В оформлении появились фоны переписки: три встроенных узора Hero Patterns
  (Steve Schoger, CC BY 4.0), отсутствие фона и собственные PNG/JPEG/WebP.
  Размытие 0–20 меняет только фон. Узоры адаптируются к светлой/тёмной теме.
  Изображения до 20 МБ/32 Мп сохраняются локальной копией до 2048 px,
  с учётом EXIF-поворота и удалением метаданных. Отмена возвращает прежний фон;
  неиспользуемые импортированные копии удаляются. Исходные файлы не меняются.
  Фон применяется ко всем чатам на этом устройстве; обмен цветовой темой
  через JSON/ссылку не передаёт изображение. Это указано в самом интерфейсе.

## Воспроизведение

Нужны .NET 8+ и графическая сессия. Из корня репозитория:

```sh
python tests/desktop_preview.py --out artifacts/mvp-review
```

Каталог результата должен быть новым. Скрипт собирает клиент и бэкенд,
использует временную БД и случайный ключ, проверяет API/WebSocket и снимает
экраны реального Avalonia UI. Логи с токенами не публикуются. `test-settings.json`
и `test-pins`, `test-wallpapers`, `test-appearance.json` в результате — изолированное состояние теста; в публичную галерею
попадают только PNG. Продакшен-аккаунты и БД не затрагиваются.

Дополнительно: `dotnet run --project desktop -- --check-preferences` и
`dotnet run --project desktop -- --check-pins` не требуют сервера.

Проверка выполнена на Windows. Нативные файловые диалоги, screen reader,
физическая IME и нативное поведение macOS/Linux требуют отдельной ручной
проверки; проверка незавершённой IME-композиции здесь программная.
