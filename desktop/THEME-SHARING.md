# Темы: файлы и ссылки

Вариант Б использует одну компоновку и независимую палитру. В меню рядом с
профилем откройте **Оформление**. Изменения показываются сразу; **Применить**
сохраняет тему, **Отмена** возвращает оформление, с которым открыли окно.

В разделе **Обмен темами**:

- **Экспорт файла** сохраняет текущую палитру в JSON; **Импорт файла** открывает
  такой файл в предпросмотре. Файл можно передать без сервера.
- **Опубликовать на сервере** создаёт публикацию на сервере, на котором выполнен вход.
  **Копировать ссылку** копирует её адрес. Чтение ссылки не требует аккаунта.
- Получатель вставляет HTTPS-ссылку и нажимает **Загрузить тему**. После этого
  можно изменить цвета и сохранить оформление либо опубликовать свою копию.
- Владелец, открыв свою ссылку на текущем сервере, видит **Обновить опубликованную**.
  Ссылка останется прежней. Чужую публикацию перезаписать нельзя.
- Публикация и обновление происходят сразу. Отмена окна отменяет локальный
  предпросмотр, но не удаляет уже опубликованную тему. Установленные копии
  не обновляются автоматически при изменении ссылки.

## Формат 1

```json
{
  "schemaVersion": 1,
  "theme": {
    "name": "Синий вечер",
    "dark": true,
    "background": "#191C20",
    "surface": "#25292D",
    "text": "#E6EAEE",
    "accent": "#8FB6ED"
  }
}
```

Название: 1–64 символа без управляющих знаков. Цвета: ровно `#RRGGBB`.
Максимум файла/HTTP-тела: 16 КиБ. Неизвестная версия отклоняется. Файл не может
подключать XAML, скрипты, шрифты, изображения или менять расположение кнопок.
Это формат палитры, а не полноценный язык разметки интерфейса.

Ссылки загружаются отдельным HTTP-клиентом: только HTTPS, без session token,
автоматических перенаправлений и credentials в URL. Размер ограничен и при
потоковом чтении, ожидание ответа и тела ограничено по времени.

## HTTP API

Пути относительно настроенного `MESSENGER_PATH_BASE`:

| Метод | Путь | Доступ | Результат |
|---|---|---|---|
| POST | `/themes` | Bearer | 201, новая публикация |
| GET | `/themes/{id}` | Публичный | 200, тема с текущей версией |
| PATCH | `/themes/{id}` | Bearer владельца | 200, новая версия |
| DELETE | `/themes/{id}` | Bearer владельца | 204, удаление публикации |

POST принимает документ формата 1. Ответ содержит `id`, `ownerId`, `version`,
`schemaVersion` и `theme`. Тело GET можно также сохранить как файл темы.

PATCH принимает ожидаемую версию и только изменяемые поля:

```json
{ "version": 1, "theme": { "accent": "#9B5671", "name": "Роза" } }
```

Версия увеличивается атомарно. Несовпадение версии — `409 theme_version`;
другой владелец — 403; неверный документ — 400; превышение размера — 413;
неизвестный/удалённый ID — 404. До 100 публикаций на аккаунт; далее
`409 theme_limit`. Чтобы исправить конфликт версии, загрузите ссылку заново.

Миграция `005_shared_themes.sql` добавляет отдельную таблицу и индекс владельца.
Существующие пользователи, сессии, сообщения и их шифрование не меняются.
При откате приложения таблицу можно оставить: прежний код её не использует.
Палитры публичные, хранятся как JSON, не содержат токенов и ключей пользователя.

## Проверки

```text
dotnet build backend -c Release
python tests/theme_exchange.py
dotnet build desktop -c Release
dotnet run --project desktop -c Release -- --check-themes https://HOST/PATH
dotnet run --project desktop -c Release -- --preview-sharing https://HOST/PATH OUTPUT
```

Последние две команды создают тестовый аккаунт и удаляют тестовую публикацию.
Используйте отдельный тестовый сервер. `--preview-sharing` проверяет кнопки
публикации, смену пресета, обновление, загрузку ссылки, неверную ссылку и отмену.
Выбор файла в нативном диалоге ОС требует отдельного ручного прохода; формат,
граница размера и сериализация проверяются автоматически.
