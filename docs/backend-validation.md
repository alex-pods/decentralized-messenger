# Проверка 19 октября 2026

Сборки бэкенда и desktop: Release, .NET 8, без предупреждений и ошибок. Интеграционные сценарии `backend/tests/integration.py` и `tests/ProtocolChecks` прошли локально на Windows и на целевом Linux x64 с ASP.NET Core 8.0.31. Проверка NuGet для бэкенда, включая транзитивные зависимости, не нашла известных уязвимых пакетов в текущем источнике advisory.

На Linux отдельно проверена миграция копии действующей БД и файлов. Количество пользователей, чатов, участников, сообщений, реакций и сессий сохранилось; `integrity_check` и `foreign_key_check` прошли. Выборочные расшифрованные сообщения и bio совпали с исходными. Проверка не меняла рабочую БД; реальные данные не покидали сервер.

Нагрузка замкнутая, без заданного RPS и без длительного выдерживания. Сеть loopback, маленькая тестовая история; исходные пароли/авторизация создаются до измеряемой фазы. На хосте работают и другие сервисы. Результаты не определяют допустимый production RPS, WAN-задержки или работу с тысячами соединений.

Проверены восстановление после перезапуска, потеря ключей, миграция legacy-строк и файлов, отсутствие исходного текста в текущем файле SQLite, откат создания группы при искусственном отказе INSERT, уникальность direct-чата при параллельных запросах, передача owner, удаление содержимого и файлов, изоляция read_at между чатами, скрытое последнее сообщение, права постороннего и исключённого участника, идемпотентность после редактирования, logout нескольких сокетов одной сессии с сохранением другой сессии, ограничения WS, схемы Swagger и их ссылки.

Существующий desktop self-check прошёл на изолированном сервере: вход, переписка, WS, группа, повторная отправка, редактирование, after_id и удаление. Встроенный режим preview отрендерил экраны входа, чата, группы, участников и профиля; личный чат, группа и профиль проверены визуально. Изменений desktop-кода нет.
